What this demo covers

  • Access tokens are kept in memory and sent as Authorization: Bearer.
  • Refresh tokens live in an httpOnly cookie and rotate on every refresh, with reuse detection.
  • Role-based access: admins manage users, everyone else gets 403.
  • Instant revocation: logout-all and password changes kill existing tokens.
